# Git in 10 commands

1. `git clone <url>`: download the repo
2. `git status`: see what changed
3. `git checkout -b feature/name`: make a new branch
4. `git add <file>`: stage a file
5. `git commit -m "message"`: save a snapshot
6. `git push -u origin feature/name`: upload the branch
7. Open a Pull Request on GitHub, review, then Merge
8. `git checkout main`: go back to main
9. `git pull`: download the latest main
10. `git branch -d feature/name`: delete the old branch

Rules: never push straight to `main`. One folder per person. Never commit `.env`.
